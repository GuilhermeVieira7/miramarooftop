# Miramar Rooftop

Site do Miramar Rooftop, em São Luís (MA).

A abertura mostra o céu do rooftop na hora real de São Luís, com o horário do pôr do sol calculado para o dia. A pessoa pode arrastar o controle para ver o céu em outra hora, do almoço até a noite. O cardápio tem busca e filtros, e a reserva monta a mensagem pronta no WhatsApp (98) 98414-2570.

O site é estático (HTML, CSS e JS puros) e não tem etapa de build. Para publicar na Vercel, importe o repositório com o preset "Other" e clique em Deploy.

- `index.html`: estrutura e textos
- `menu-data.js`: cardápio e preços (edite aqui)
- `styles.css`: visual
- `script.js`: céu ao vivo, cardápio e reserva
- `assets/`: logotipo e fotos
